# Jarvis-FOSS

Jarvis-FOSS is an AI-powered command-line interface (CLI) application designed for intelligent interaction, task automation, and codebase management.

## Architecture

The project is structured into modular components to ensure maintainability and separation of concerns:

- `capabilities/`: Contains specialized function modules and resolver logic for system extensions.
- `checks/`: Quality assurance and safety validation modules (e.g., action confirmation, error checking).
- `commands/`: CLI command definitions (e.g., file operations, browser interaction, memory management).
- `config/`: Configuration schemas and LLM settings.
- `core/`: Fundamental infrastructure components (logging, networking, routing).
- `memory/`: System context management and persistent storage mechanisms.
- `models/`: Data models and definitions.
- `reasoning/`: Core AI decision-making engines (planning, intent classification).
- `src/`: Application entry point (`main.py`) and specific source implementations, including backend drivers for LLM integration.
